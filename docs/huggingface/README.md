# MorphGuard log datasets

Raw and derived data behind MorphGuard (Large-Scale Log Analytics for Cloud
Security). Code: https://github.com/Ashwin-deals/large-scale-log-analytics-backend.
Fetch everything with `python3 scripts/download_dataset.py --source all --with-derived`.

## Layout

| Path | What it is | Labels |
|---|---|---|
| `HDFS.log`, `anomaly_label.csv` | LogHub HDFS_v1: 11,175,629 lines, 575,061 blocks | Ground truth per block (16,838 anomalous) |
| `openstack/` | LogHub OpenStack: `openstack_normal1.log`, `openstack_normal2.log`, `openstack_abnormal.log`, `anomaly_labels.txt` | By run: a session from the abnormal run is labeled Anomaly. Only 4 instances are documented as faulty. |
| `apache/Apache.log` | LogHub Apache error log, 56,481 lines | None |
| `apache/injected/` | `Apache_INJECTED.log` and `_labels.csv`, from `scripts/inject_apache_anomalies.py` (seed 42) | **Injected** anomalies |
| `cloudtrail/` | flAWS.cloud CloudTrail logs, `flaws_cloudtrail00-19.json.gz`, 1,939,207 events | None. MorphGuard derives **weak rule-based** labels. |
| `django/` | `django_SYNTHETIC.log` and `_labels.csv`, from `scripts/generate_django_logs.py` (seed 42) | **Synthetic** |
| `derived/hdfs/` | `features.csv`, `block_metadata.csv`, `dataset_stats.json` built from the HDFS log | Not applicable |
| `derived/vocab/<source>/` | `category_encoders.json`: the category vocabulary every model is stamped with. Scoring refuses to run without it. | Not applicable |

## What the labels can and cannot support

- **HDFS:** validated ground truth.
- **OpenStack:** a labeled case study. The labels mark which run a session came from, not which session failed.
- **Apache, CloudTrail, Django:** pipeline tests with injected, rule-based or synthetic labels. F1 on these measures agreement with those labels, not with real incidents.

## Sources and credit

- HDFS, OpenStack and Apache: LogHub, https://github.com/logpai/loghub (Zenodo record 8196385).
  Please cite the LogHub paper (Zhu et al., *Loghub: A Large Collection of System Log Datasets for AI-driven Log Analytics*, ISSRE 2023).
  The OpenStack logs originate from the DeepLog paper (Du et al., CCS 2017).
- CloudTrail: the flAWS.cloud logs published by Scott Piper / Summit Route, http://flaws.cloud/.
- Injected Apache and synthetic Django files: generated by MorphGuard's scripts.
